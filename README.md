My Personal Website

Introduction
Welcome to my personal website. This website
was developed as part of my Web Technologies
Activity 3.

About the Website
The website introduces me, my hobbies, my
learning plan, my photos, and my media. It also
includes examples of my learning and a contact
form demonstration.

Technologies Used
HTML5 for webpage structure
CSS3 for styling and responsive design
JavaScript for interactive features

Features
Responsive website layout
Light and dark theme switch
Contact form validation and message
preview
Interactive photo gallery with Previous and
Next buttons
Search and reset functionality in the My
Work section
Audio and video playback

Project Structure
index.html — main webpage
css/styles.css — website styling
js/script.js — interactive functionality
images/ — website images, if used
videos/ — audio and video files, if stored

How to Run
Open index.html in a web browser to view the
website.

Contact Form Notice
The contact form demonstrates browser-side
validation and a message preview. It does not
send messages to a server.
